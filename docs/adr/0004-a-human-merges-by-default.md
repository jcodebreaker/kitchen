# A human merges by default

Kitchen never merges a pull request on its own unless the project opts in, and even then only for low-risk tickets with no UI or security surface. The reference factory lets its approver agent merge; we don't, because Kitchen runs on other people's repos and trust has to be earned with the ledger's numbers first. Cost is shown per job on the dashboard but never stops a job: Kitchen's purpose is structure, not saving money.
